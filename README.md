# PostgreSQL Learning

Dokumentasi pembelajaran PostgreSQL secara terstruktur yang mencakup SQL, relational database, database design, data querying, dan data analysis melalui praktik dan studi kasus.

Repository ini menjadi bagian dari learning portfolio saya dalam membangun pemahaman dan kemampuan di bidang database serta data.

---

## 🎯 Learning Goals

Pembelajaran ini bertujuan untuk:

* Memahami fundamental PostgreSQL dan relational database
* Menguasai SQL untuk data definition, data manipulation, dan data querying
* Memahami database design dan relational data modeling
* Memahami relationship antar-table
* Menggunakan Primary Key dan Foreign Key
* Menguasai JOIN untuk menggabungkan data dari beberapa table
* Menggunakan aggregate functions untuk data analysis
* Memahami indexing dan query performance
* Membangun fondasi database untuk kebutuhan data analysis dan backend development

## 🧠 Learning Approach

Setiap learning session mengikuti alur:

```text
Concept
   ↓
Example
   ↓
Practice
   ↓
Experiment
   ↓
Analysis
   ↓
Documentation
   ↓
Git Commit
```

Fokus pembelajaran bukan hanya pada menghafal SQL syntax, tetapi juga memahami **konsep, alasan penggunaan, struktur data, serta cara menyelesaikan permasalahan menggunakan database**.
